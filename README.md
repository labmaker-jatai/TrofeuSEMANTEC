# Troféu da SEMANTEC 2026

Modelo de troféu desenvolvido para a premiação da **25ª Semana de Educação, Ciência e Tecnologia (SEMANTEC) do IFG – Câmpus Jataí**, realizada em 2026.

O projeto foi desenvolvido para fabricação digital por meio de **impressão 3D**, com os componentes modelados e disponibilizados em arquivos individuais no formato `.STL`, permitindo maior flexibilidade na impressão, montagem e personalização dos troféus.

## Estrutura do projeto

O troféu é composto por uma base, elementos decorativos e legendas de identificação das três colocações (1º, 2º e 3º lugar).

### Arquivos para impressão 3D

| Arquivo | Descrição |
|---|---|

| [Legenda - 1° Lugar.stl](https://github.com/labmaker-jatai/TrofeuSEMANTEC/blob/main/Legenda%20-%201%C2%B0%20Lugar.stl) | Identificação do troféu destinado ao primeiro lugar. |
| [Legenda - 2° Lugar.stl](https://github.com/labmaker-jatai/TrofeuSEMANTEC/blob/main/Legenda%20-%202%C2%B0%20Lugar.stl) | Identificação do troféu destinado ao segundo lugar. |
| [Legenda - 3° Lugar.stl](https://github.com/labmaker-jatai/TrofeuSEMANTEC/blob/main/Legenda%20-%203%C2%B0%20Lugar.stl) | Identificação do troféu destinado ao terceiro lugar. |
| [Troféu.stl](https://github.com/labmaker-jatai/TrofeuSEMANTEC/blob/main/Trof%C3%A9u.stl) | Base estrutural do troféu. |

## Fabricação e montagem

Os componentes foram separados em arquivos individuais para facilitar a organização da impressão 3D e a montagem final.

O elemento decorativo foi projetado para utilização de seis cores, proporcionando um acabamento visual diferenciado. As legendas permitem identificar facilmente a classificação de cada premiado.
